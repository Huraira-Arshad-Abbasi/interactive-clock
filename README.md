# Interactive Clock with Image Backgrounds

A dynamic clock that displays the current time over a background image. Clicking the weather-themed buttons swaps the background image in real time using JavaScript.

## Features

- Live clock updating every second via `setInterval`
- 4 background themes switchable by icon buttons (snow, cloudy, beach, sunny)
- Background images swap dynamically using JavaScript event delegation

## Tech

HTML · CSS · Vanilla JavaScript

## How to Run

Open `index.html` in any browser — no build step needed.
